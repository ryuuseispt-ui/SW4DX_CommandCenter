# SW4DX_CommandCenter
기존 파트너 명령창에서 다른 아군 장수에게도 대기·호위·공격을 지시하는 독립 모드입니다.
# 전국무쌍4 DX 커맨드센터 v1.0.0 — 아군 명령·장수 임시 조종

파트너에게만 내리던 명령을 다른 아군 무장에게도 내릴 수 있는 독립 모드입니다. 기존 명령창에서 아군을 골라 대기·호위·공격을 지시하고, 선택한 장수를 잠시 직접 조종할 수 있습니다.

오리진 모드 없이 사용할 수 있으며, 오리진과 함께 설치하는 구성도 지원합니다.

## 주요 기능

- **아군 대상 선택:** 명령창에서 L2/R2로 아군 무장을 순서대로 선택합니다. 이름·초상화·지도 표시가 선택 대상에 맞춰 바뀝니다.
- **기존 명령창 활용:** 대기·호위·공격과 목적지 선택을 원작 조작으로 지정합니다.
- **전술 목록:** 왼쪽에 출전 아군의 전체 이름·체력 비율·명령 상태를 8명씩 표시합니다.
- **명령 상태 구분:** 직접 내린 명령은 노란색 `임무 중`, 원작 지시나 대기는 회색 `별도 임무 중`으로 표시합니다. 두 지시가 함께 있으면 같이 표시합니다. 처음부터 대기 중인 장수도 명령창을 열 때 읽어 표시합니다.
- **직접 명령 우선:** 사용자가 내린 명령을 수행하고, 완료하거나 취소하면 보관된 원작 지시가 유효한 경우 재개합니다.
- **장수 임시 조종:** 전술창에서 선택한 아군을 직접 조종합니다. 그 인물의 전투 중 체력·능력치·장비를 사용하고 화면의 체력과 초상화도 맞춰 표시합니다. 영구 영입이나 성장 데이터 변경 기능은 아닙니다.
- **복귀 처리:** 본래 인물로 돌아올 수 있으며, 전사·강제 퇴장·진영 변경·실제 메뉴·결과 화면에서도 복귀하도록 처리합니다.

## 설치

기준 환경은 Windows의 Steam판 전국무쌍4 DX이며, 현재 한글패치 환경을 기준으로 제작·검사했습니다. 오리진은 필수 설치물이 아닙니다.

1. 게임을 완전히 종료합니다.
2. 압축파일 안의 아래 **3개 파일**을 `SamuraiWarriors4DX.exe`가 있는 폴더에 복사합니다.

```text
D3DCompiler_43.dll
SW4DX_AlliedOrders.dll
SW4DX_AlliedOrders.ini
```

3. 게임을 실행하고 전투 중 파트너 명령창을 엽니다.

`D3DCompiler_43.dll`은 함께 배포하는 공통 로더입니다. 기존 오리진용 공통 로더를 이것으로 갱신해도 오리진과 기존 선택 모듈을 계속 불러오도록 구성했습니다. 게임 폴더의 기존 로더는 복사하기 전에 따로 보관해 두세요. 다른 제작자의 동명 DLL과의 조합은 개별 확인이 필요합니다.

## 조작

| 화면 | 입력 | 기능 |
| --- | --- | --- |
| 전술 명령창 | L2 / R2 | 이전 / 다음 아군 선택 |
| 전술 명령창 | 원작 명령 조작 | 대기·호위·공격·목표 지점 지정 |
| 전술 명령창 | L2+R2 동시 입력 | 선택 장수에게 내린 직접 명령 취소·자율 복귀 |
| 전술 명령창 | 원작 파트너 교대 버튼 · 기본 Tab | 선택 장수 임시 조종 |
| 임시 조종 중 일반 전투 | 같은 교대 버튼 | 본래 조작 인물로 복귀 |

L2/R2 선택은 XInput 컨트롤러 입력을 사용합니다. Xbox 계열 패드에서는 LT/RT입니다. 조종 전환은 원작의 파트너 교대 입력을 사용하므로 패드에서는 해당 기능에 배정된 버튼을 누르면 됩니다.

## 설정과 해제

`SW4DX_AlliedOrders.ini`의 `[AlliedOrders]`에서 `Enabled=1`이면 켜지고 `Enabled=0`이면 꺼집니다. 설정은 게임을 재실행하면 적용됩니다. 다른 모드의 INI를 수정할 필요가 없습니다.

완전히 제거하려면 게임을 종료한 뒤 `SW4DX_AlliedOrders.dll`과 전용 INI만 제거합니다. 오리진이나 다른 선택 모드를 사용한다면 공통 로더는 그대로 둡니다. 설정만 끄는 방식으로도 사용할 수 있습니다.

## 오리진과 함께 사용할 때

새 여정을 시작할 필요 없이 기존 진행을 이어서 사용하는 구성을 목표로 검사했습니다. 이 배포본에는 오리진 본체·대사팩·진행 기록·세이브 파일이 들어 있지 않으며, 설치 시 그것들을 덮어쓰지 않습니다. 명령 모드의 명령과 조종 정보는 해당 전투에서만 관리합니다.

공통 로더의 단독/병행 불러오기, 두 모드의 설치 순서, 저장·불러오기 콜백 보존 및 합성 여정 5개의 기록 유지 검사를 진행했습니다. 상세 범위와 결과는 함께 제공하는 검증 문서에 기록합니다. 실제 사용자의 저장 파일을 변경하거나 다른 PC에서 게임 전체를 완주한 검사는 아닙니다.

## 사용 시 참고

- `별도 임무 중`에는 원작의 일반 대기도 포함됩니다. 모든 표시가 강제 스토리 임무라는 뜻은 아닙니다.
- 원작 지시가 있는 장수도 명령하거나 조종할 수 있습니다. 임무 진행을 계속하려면 직접 명령을 취소하고 원작 지시로 돌아가게 해 주세요.
- 먼 장수는 표시·동작 초기화가 준비될 때까지 전환을 기다릴 수 있습니다. 화면의 인물 수가 가득 찼거나 원작 불러오기가 실패하면 전환이 성립하지 않을 수 있습니다.
- 1인 플레이 기준입니다. 분할 화면 2인 플레이에서의 확장 조작은 제공하지 않습니다.
- 모든 전투의 특수 연출·강제 퇴장·기승 조합을 실제 플레이로 검증한 것은 아닙니다. 마지막 대기 표시 보완도 내부 검사를 통과한 상태이며 실제 첫 화면 확인은 별도입니다.
